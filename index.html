    微信里怎么用

    方法一：键盘说话（推荐，就在微信里用）

    1. 点对话页绿色的「🎤 键盘说话」按钮。
    2. 点一下输入框，手机上会弹出键盘。
    3. 点键盘上的 🎤（有的手机叫“语音输入”），说一句中文。
    4. 说完点「翻译」，屏幕上会出现放大的英文，直接给乘客看。

    大部分安卓手机的键盘麦克风在空格键旁边；苹果手机在键盘右下角。

    方法二：改成在浏览器里用（可以用按住说话）

    1. 点微信右上角的 ···。
    2. 选「在浏览器打开」。
    3. 浏览器里点「分享」→「添加到主屏幕」，以后从桌面图标直接点开，不用再经过微信。

    为什么微信里不能按住说话

    微信内置的浏览器不允许网页使用麦克风录音，这是微信的限制，所有网站都一样。键盘说话用的是手机系统的语音输入，所以在微信里也能用。

    使用说明

    司机怎么用

    1. 点「🇨🇳 我说中文」，按住大按钮说中文，说完松手。
    2. 助手听写后自动翻译，并直接读出英文给乘客听。
    3. 涉及到钱、地址、时间、电话、航班号时，助手会先让您确认「我听到的对不对」，确认后才翻译。
    4. 把手机屏幕转给乘客看，上面是放大的英文句子。

    乘客怎么用

    1. 点「🇬🇧 Passenger」，把手机递给乘客。
    2. 乘客按住按钮说英文，松手后助手读中文给您听。

    不用说话的用法

    点「常用表达」，选好场景，一句一句点，助手会直接播报对应的语言，最稳、最快。

    听不清 / 手机不认语音

    请用 Chrome、Edge 或 Safari（iOS 14.5 以上），并且必须通过 https 或 localhost 打开，网页才有权限用麦克风。实在不行，用「打字输入」或「常用表达」。

    在微信里点开链接

    微信内置的浏览器不允许网页录音，所以「按住说话」在微信里会没反应。微信里请用键盘说话：点绿色的「🎤 键盘说话」→ 点输入框 → 点键盘上的 🎤 说中文 → 点「翻译」，然后把屏幕上的英文大字给乘客看。

    想用「按住说话」的话，点右上角 ···，选「在浏览器打开」，再允许麦克风；打开后建议选「添加到主屏幕」，以后从桌面图标点开就是全屏的，不用再经过微信。
